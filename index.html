Different ways to find the path.

Breadth First Search

Explores neighboring cells level by level. Finds the shortest path in an unweighted maze.

Finds the shortest path by expanding the cell with the lowest known distance.

ABOUT THIS PROJECT

Algorithms you can actually see.

MazeLab is an interactive educational project that demonstrates maze generation and pathfinding. It helps learners understand how search algorithms explore a problem space and discover a route from start to finish.
